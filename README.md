# 📊 Excel 智能分析助手

> 上传 Excel / CSV，用一句话描述需求，AI 自动规划、执行、解读——让不懂统计的人也能做专业数据分析。

## ✨ 核心特性

### 🤖 自然语言驱动
用中文描述你的需求，DeepSeek 自动拆解为执行计划并逐步完成：
- "找出影响销售额的主要因素"
- "按部门汇总销售额，画柱状图"
- "清理缺失值，然后建立多个回归模型比较哪个最好"
- "把数据按每 5 列拆分为多张表"

### 📈 12 种统计分析方法

| 分析类型 | 说明 |
|----------|------|
| **影响因素分析** | 随机森林特征重要性，找出哪些变量最影响目标 |
| **多模型对比** | 线性/岭回归/随机森林/梯度提升/神经网络赛马 |
| **多元线性回归** | 回归系数 + p 值显著性检验 |
| **神经网络回归** | MLP 深度学习建模 |
| **岭回归/套索回归** | 处理多重共线性，自动筛选变量 |
| **逻辑回归** | 二分类预测 |
| **聚类分析** | K-Means 自动分群，输出各簇画像 |
| **主成分分析** | PCA 降维，保留主要信息 |
| **方差分析** | ANOVA 检验各组均值差异是否显著 |
| **时间序列** | 趋势分析与预测 |
| **相关性分析** | Pearson 相关系数 + 散点图 |
| **交叉分析** | 列联表 + 卡方检验 + Cramér's V 关联强度 |

### 💬 通俗业务解读
每次分析结束后，AI 自动生成一份面向非专业人员的解读报告：
- 📊 **一句话结论**：最核心发现是什么
- 🔍 **详细解读**：每个数字是什么意思、对业务有什么含义
- 💡 **业务建议**：2-3 条可操作的具体建议
- ⚠️ **注意事项**：分析局限性提醒

### 🛠️ 数据处理能力
筛选、排序、去重、填充缺失值、新增计算列、分组聚合、多列拆分、多 Sheet 合并……13 种原子操作可自由组合。

### 📊 交互式图表
自动生成 ECharts 图表（柱状图/折线图/饼图/散点图/面积图），分析结果可视化一键呈现。

## 🚀 使用方式

1. **上传文件**：支持 `.xlsx` / `.xls` / `.csv`
2. **输入指令**：用中文描述你想做什么
3. **查看结果**：通俗解读 + 技术报告 + 交互图表
4. **下载报告**：一键下载完整 Excel 分析报告

## ⚙️ 环境变量配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `DEEPSEEK_API_KEY` | SiliconFlow / DeepSeek API Key | 必填 |
| `DEEPSEEK_BASE_URL` | API 基础地址 | `https://api.siliconflow.cn/v1` |
| `DEEPSEEK_MODEL` | 使用的模型 | `deepseek-ai/DeepSeek-V3` |

## 🏗️ 技术栈

- **后端**：FastAPI + Python 3.10
- **AI 规划**：DeepSeek-V3（自然语言 → 执行计划）
- **机器学习**：scikit-learn / scipy / statsmodels
- **前端**：Alpine.js + ECharts + marked.js
- **数据处理**：pandas / numpy / openpyxl
